EchoMind Voice Assistant

Olivia — a Windows desktop voice assistant in Python. Speak a command; it listens, acts, and answers out loud using speech-to-text, text-to-speech, and web/OS automation.

View on GitHub Install

Speech I/O

SpeechRecognition for input, pyttsx3 SAPI5 voice for spoken replies.

Web search

Google, YouTube, and Wikipedia lookups by voice.

Media & messaging

Play YouTube songs, send WhatsApp messages and emails via pywhatkit.

Desktop automation

Screenshots, mouse/keyboard control, app launching with pyautogui.

Info at a glance

Time, date, weather, jokes, IP address, internet speed test.

GUI

Simple Tkinter interface alongside voice control.
